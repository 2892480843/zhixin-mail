## QQ 参数

| 字段 | 内容 |
| --- | --- |
| 邮箱地址 | 使用者的完整 QQ 邮箱地址 |
| 收件方式 | IMAP（同步邮箱文件夹） |
| 收件服务器 | `imap.qq.com` / `993` / TLS（加密连接） |
| 发件服务器 | `smtp.qq.com` / `465` / TLS |
| 密码 | QQ 生成的客户端授权码 |

[QQ 官方授权码说明](https://help.mail.qq.com/detail/106/985)：在账号与安全 → 安全设置开启客户端服务并生成授权码。身份验证与新凭据生成由用户完成，已有授权码只输入宿主表单，不能写入代码、公开截图或提交材料。宿主初始服务器为 Gmail，连接 QQ 前需替换。
