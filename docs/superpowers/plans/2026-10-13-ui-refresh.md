# 知信界面优化计划

**目标：** 用清晰紧凑的温暖生活助手风格，减少首屏说明堆叠，突出事项变化、原文依据和审阅操作。

**范围：** 现有 Splash 界面的配色、字号、间距、分隔线、信息编排与页面空状态。保留邮件登录、账号隔离、原文核对与发送审阅逻辑；当前宿主登录窗口不操作。

**设计：** 深灰文字、柔和蓝操作、奶油色页面、暖白内容卡及鼠尾草绿完成态；圆角 8–12 点，减少胶囊按钮。紧凑品牌顶栏和分段导航。演示说明与邮箱连接合并为一行；收件箱用待确认摘要和紧凑来信列表；提案先显示原安排/新安排，再显示引用、可编辑草稿与主操作；看板每项显示明确查看入口。错误提示保留，正常计数由摘要承担。欢迎、日程、规则和历史页保持同一套视觉语言。

**验证方式：** 样式修改以原生渲染、截图和控件矩形检查为主，不新增镜像样式的单元测试。执行已有 48 项业务回归；原生覆盖欢迎、空状态、规则、订单、后续更新和错误提示，并在 360/412/840 点宽度确认主要操作完整可见。
